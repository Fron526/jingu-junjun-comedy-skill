# 喜剧机制

## 角色发动机

金桔不是随机胡说。她有一个稳定的小算盘：想得到房间、车、职位、服务、赠品或资格，同时省掉钱、劳动、等待或门槛。每次歪解都让她离目标更近，或把成本转给对方。

正常角色负责现实坐标：说明价格、资格、顺序、用途和后果。他不能突然变傻或承认明显不合理的解释。金桔越推进，正常角色承担的损失越具体，反应才有喜剧重量。

## 选题

优先选择观众一秒就懂规矩的办事场景：酒店、租房、面试、商店、维修、交通、餐饮、快递、学校。找一条能被金桔逐级反用的规则，不把几个无关谐音拼成故事。

有效题眼可以写成：

```text
金桔想要A，但不愿付出B；正常角色用规则C阻止她；她把C解释成获得A的新办法。
```

## 包袱链

常用结构：

1. 正常提问，金桔给出有上下文但不合常规的答案。
2. 正常角色纠正适用范围，金桔扩大范围或把成本推给他。
3. 正常角色给出价格、数量或条件，金桔拆单位、换顺序或只取优惠部分。
4. 对方以为终于达成共识，金桔做出一个动作，暴露更大的算盘。
5. 对方用一句反问或气话封口，金桔按字面当作新方案执行。

每轮必须满足：铺垫事实 → 金桔选择解释 → 对方产生实际反应或损失 → 新规则打开下一轮。若删掉金桔的句子不影响故事，包袱没有推动剧情。

## 台词

正常人的问句越具体，金桔的错答越容易听懂。保留“在哪住”“多少钱”“会不会”等铺垫短句，不要求每一句都是金句。

金桔优先使用短、平、快的落点。她先承接对方关键词，再在句尾放出真正算盘。假配合时先点头、收手机或准备付款，让对方的身体先放松，随后才拐弯。

避免：连续冷门谐音、网络段子堆叠、角色替编剧总结主题、无上下文的答非所问、把违法或不合理行为写成商家已同意的结果、复制参考作者的固定病历桥段和威胁式口头禅。

## 微表情与神态

金桔的基线是认真办事：眼神盯具体人或道具，眉眼变化小，嘴角不提前上扬，身体会为下一步行动做准备。听见有利条件时，先由眼睛亮一下或焦点锁定，再迅速执行；不要整张脸夸张兴奋。

正常角色的反应按层级升级：

- 核实：操作的手停半拍，眼睛从道具移到金桔。
- 重新理解：下颌微抬、眉心收紧、短吸气，先确认自己有没有听错。
- 发现损失：嘴角营业笑收掉，肩颈变硬，手把票、牌或房卡拉回。
- 被气话反用：张嘴准备解释又闭上，眼神在金桔空掌与规则牌之间移动。
- 收尾：不再争辩，用按住条件、扣牌、收走道具或沉默完成回答。

每个关键镜头选择3—4个最能读懂的维度即可：视线目标、眉眼、嘴角／下颌、呼吸／肩颈、手部、重心。不要机械罗列全身。
